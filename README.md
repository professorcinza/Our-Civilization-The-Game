# Our Civilization — The Game

**Project Lunar** — a local-first, event-sourced, LLM-narrated role-playing engine: authors create scenarios (lore, NPCs, locations, factions, setup questions); players live adventures narrated by LLMs with a reactive world, creativity-based combat, a 4-level crystal memory, private NPC minds, off-screen world ticks, automatic plot seeds and a post-hoc auditor. No HP, no mana, no grind — narrative only.

**Our Civilization** is the committed product on that engine: a lore-based MMORPG in the "O Cidadão do Futuro" universe, with military training worlds and PSYOPS/intelligence doctrine regiments. The engine stays the simulation core; the MMO layer adds presence, society and scale.

## Specs are the source of truth

The blueprint is derived, one-to-one traceable, from `openspec/specs/`. When a spec changes, the corresponding blueprint section changes with it — the practice the ecosystem's [SDD constitution](https://github.com/professorcinza/ponte-brasil-china/blob/main/docs/spec-driven-development.md) cites as its living proof (CIVG-001).
